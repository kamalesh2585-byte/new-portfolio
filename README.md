# Kamalesh 3D Portfolio

The exact local source of the black-and-white interactive Three.js portfolio published on Omma. It includes five animated scenes, wheel and touch navigation, bloom, smooth camera movement, and an invert mode.

## Run locally

Because JavaScript modules require a web server, run one of these commands in this folder:

```powershell
npx serve .
```

Then open the URL printed in the terminal.

## Customize

- Edit portfolio text, links, styles, Three.js objects, and animation timing in `app.js`.
- `styles.css` is an unused earlier stylesheet and is not loaded by the exact version.
